# Kuantum Karar Motoru: Evet Ama Hayır

## Bu Nedir Ya?

Bu repo, insanlığın en büyük problemini çözer: **Karar verememek.**

Ama çözmez. Çünkü kuantum mekaniği kullanır. Her cevabı hem evet hem hayır yapar. Çalıştırdığınızda fincanı ters çevirir (simülasyon tabii). Türkçe konuşur, Türkçe düşünür, Türkçe yanlış yapar.

### Nasıl Çalışır?

1. Sorunuzu sorun.
2. 3 saniye bekleyin (ısınma süresi).
3. Rastgele "Evet ama hayır" varyasyonu alın.
4. Fincanın ters çevrildiğini izleyin.
5. Karar veremediğiniz için mutlu olun.

### Kurulum

```bash
python karar_motoru.py "Bugün kahve içeyim mi?"
```

Veya interaktif:

```bash
python karar_motoru.py
```

### Özellikler

- Gerçekten çalışır (Python 3+).
- Abartılı derecede ciddi görünür ama saçmadır.
- Her çalıştırmada farklı ama hep aynı.
- Gizli mesajlar içerir (kodda saklı, bakma).
- Copilot bile "bu ne ya" der.

### Neden Var?

Çünkü GitHub'da normal repo açmak sıkıcı. Bu yüzden kuantum karar verdik: Evet açalım ama hayır açmayalım. Ama açtık.
